OAuth и API

Yandex OAuth

Работает через /auth/yandex/login. Нужны YANDEX_CLIENT_ID и YANDEX_CLIENT_SECRET.

VK OAuth

Работает через /auth/vk/login. Нужны VK_CLIENT_ID и VK_CLIENT_SECRET.

JWT API

Токены выдаются после email/пароль логина или регистрации. API принимает Bearer access token или веб-сессию.
